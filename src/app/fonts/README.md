# Fonts

`montserrat-latin.woff2` — Montserrat (Latin subset), used only for the Wodejia wordmark. Copyright © The Montserrat Project Authors,
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling and redistribution.

It is bundled (instead of fetched from Google Fonts at build time) so builds never depend on a third-party download and visitors'
browsers make no request to Google for it.
